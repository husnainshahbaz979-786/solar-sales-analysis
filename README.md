# Solar Sales Analysis

A Python data analysis project for a solar energy company.

## What it does
- Generates 500 fake solar sales records
- Cleans the data (duplicates, missing values)
- Analyzes total sales by Region, Product, and Sales Rep
- Creates a bar chart for sales by region

## How to run
```bash
pip install -r requirements.txt
python src/load_data.py
python src/analyze_data.py
